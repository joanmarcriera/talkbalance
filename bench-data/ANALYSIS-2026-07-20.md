## Findings (indicative, n too small to close T3)

- **Separation (ERes2Net, 1 ref):** same-speaker 0.906 vs different-speaker
  0.144 / 0.168 — a 0.74 gap. Strongly encouraging; consistent with the desktop
  spike. Threshold ~0.4–0.5 would separate these perfectly, but n=3.
- **Latency (n=19, on CPH2609):** 23–102 ms inference per second of audio
  (median 37) — 10–40× real-time. Performance is a non-issue.
- **Anomaly to investigate:** segments up to 9224 ms observed despite VAD
  `maxSpeechDuration=3.0` — force-split appears not to cap segment length as
  expected (sherpa VAD may emit the full utterance on flush/silence). Matters
  for live-bar update cadence (T11); check before tuning.

## Protocol for the redo (~5 min, closes T3)

1. Open Bench → select **CAM++** → Start → Capture ref A (person 1 talks ~8 s)
   → Capture ref B (person 2 talks ~8 s) → converse normally ~2 min → Stop.
2. Toggle **ERes2Net** (refs clear by design) → Start → re-capture A and B →
   converse ~2 min → Stop.
3. Tell Claude — data is pulled from the persisted file, not logcat.

Refs must be captured *after* selecting the model: toggling wipes them
(embedding spaces differ, dim 512 vs 192).
